# CacheKit P1 ready-gated prefetch q9 result

## Decision

`ready-d2` is rejected on both tested hosts. The completion-bearing path is
active, but it does not meet the frozen `+3.00%` q9 K/s/core advancement gate.
Do not screen depths 3/4, expand this candidate to 15 queries, or attribute a
performance win to ready-gated dispatch.

Each result below uses its same-host, same-artifact, contemporaneous control as
the denominator. The two host results are not pooled.

All four legs used 100,000,000 events, 8 TaskManagers, 16 slots, full 8-TM CPU
metric coverage, and measured fewer than 16.05 cores. The disjoint-ownership
CPU collector was valid for both TaskManager containers; the generic recursive
process-tree collector is intentionally not used because each receiver PID is
an ancestor of multiple sender JVMs.
